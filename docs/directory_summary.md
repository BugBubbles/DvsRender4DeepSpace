# Directory Summary

Top-level layout:

- `.cache/` build and tool cache
- `.git/` git metadata
- `apps/` command-line apps (`main_*.cpp`)
- `bin/` built executables (CMake runtime output)
- `build/` build tree (out of source)
- `config/` YAML config files
- `docs/` documentation and bundle format notes
- `include/` public headers
- `src/` C++ and CUDA implementation
- `tools/` Blender export scripts
